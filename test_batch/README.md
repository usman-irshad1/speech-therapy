# `test_batch/` Directory — Evaluation Audio Clips

### Overview

This folder contains held-out audio evaluation clips (`eval_1.wav` through `eval_10.wav`, `sample_1.mp3` through `sample_5.mp3`) used for testing the model's CTC phoneme recognizer and real-time audio pipeline.
